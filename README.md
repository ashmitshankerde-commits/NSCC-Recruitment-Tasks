# NSCC SRM Technical Task Submission

## How to Run the Project
1. Download or clone this repository.
2. Open `Task1.html` in a web browser to use the Signup Form and Dashboard.
3. Open `Task2.html` in a web browser to view the Personal Introduction Portfolio.

## Features Implemented
**Task 1 (Signup Form & Dashboard):**
- Client-side input validation for empty usernames, proper email formatting via Regex, and password length.
- Custom bitwise password hashing before storage.
- DOM manipulation to render entries dynamically into a dashboard table.
- **Brownie Feature:** Functional Delete button tied to `localStorage`.

**Task 2 (Personal Introduction Page):**
- Glassmorphism UI design with animated CSS gradients and interactive hover elements.
- Fully responsive layout for desktop and mobile devices.
- **Brownie Feature:** Dark/Light mode toggle that saves user preference using `localStorage`.
